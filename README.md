# 🏔️ Elashian Haven

A responsive, modern website for a mountain resort & hotel — showcasing an immersive user experience built with **HTML**, **CSS**, and **JavaScript**.

---

## 📁 Repository Structure

Elashian‑Haven/
├── js/ → Interactive behavior & UI enhancements
├── src/ → Primary HTML views (e.g., ElashianHaven.html)
├── styles/ → Modular CSS for layout, themes, responsiveness
└── README.md ← This file

---

## ✨ Features

- **Responsive design** — adapts to desktop, tablet, and mobile
- **Smooth scrolling & animations** implemented via JS
- **Modular CSS organization** for easy maintenance
- **Accessible navigation** and improved UX for resort browsing
